# Minish Cap DSi — E25

**Avance experimental basado en el motor original.** Intenta pasar automáticamente del título original a mostrar un primer cuadro de la habitación original cargada desde una ROM europea propia. No es jugable, no tiene audio y el build ARM9 no ha sido validado aquí.

Ver [README_E25.md](README_E25.md) para instrucciones, pruebas y límites.
